# LAST GENERATOR

A Nigerian urban survival shooter. 20 missions, 12 weapons, 3 vehicles, 5 factions, 3 endings.
Single file, no build step. Works on desktop and phone. Progress saves in the browser.

Controls: WASD move, mouse aim/shoot, Shift sneak, E use or drive, Z switch weapon, Q medicine.
Phone: left thumb move, FIRE, USE, GUN, SNEAK, MED.

Deploy: Vercel (import repo, framework "Other") or GitHub Pages (main branch, root).
