# LAST GENERATOR

A Nigerian urban survival shooter, built from the concept document. This is the playable MVP: **Night One, "Keep the Lights On"**.

Single file, no build step, no dependencies. Works on desktop and phone.

## What is in this build
- Dynamic power grid: OFF, LIMITED, STABLE, OVERLOADED (changes light, CCTV and how far lights reach)
- Generator fuel, ammo and medicine
- Stealth: darkness, line of sight, noise, CCTV
- Three ways through: fight, sneak or cut the Syndicate generator, or trade medicine for fuel
- One Power Choice with two endings (Clinic or Market)

## Controls
Desktop: WASD move, mouse aim and shoot, Shift sneak, E use, Q medicine.
Phone: left thumb to move, FIRE (auto-aims), USE, SNEAK, MED.

## Deploy
Vercel: import this repo, framework "Other", deploy. GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
